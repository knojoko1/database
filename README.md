# Database Management & Practice Repository

Welcome to my database learning and practice repository (`knojoko1/database`)! This space is dedicated to exploring relational and non-relational database concepts, practicing SQL queries, designing efficient schemas, and managing data persistence.

---

## 📂 Repository Structure

The repository is organized into structured directories to keep queries, schemas, and connection scripts clean and modular:

*   **`sql/`**: Fundamental SQL practice scripts (DDL, DML, queries, joins, aggregations, and subqueries).
*   **`schemas/`**: Database design schemas, ER diagrams, and normalization examples.
*   **`migrations/`**: Database migration scripts and version control for database changes.
*   **`nosql/`**: Practice and examples using NoSQL databases (e.g., MongoDB, Redis).
*   **`projects/`**: Mini-projects and integration scripts connecting databases with backend applications.

---

## 🚀 Getting Started

To run and practice the database scripts in this repository locally:

### Prerequisites
Make sure you have a database management system installed, such as:
*   **Relational Databases**: PostgreSQL, MySQL, or SQLite.
*   **NoSQL Databases**: MongoDB (optional).
*   A database GUI client like **DBeaver**, **DataGrip**, or **pgAdmin**.
